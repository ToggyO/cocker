# cocker

Учебный Linux-only runtime для запуска изолированных процессов.

Проект развивается по методологии Spec Driven Development. Источником требований являются документы в `docs/specs/`, архитектурные решения фиксируются в `docs/adr/`, а текущий контекст работы между сессиями хранится в `docs/session-context.md`.

## Рабочий процесс

1. Сначала уточняется спецификация.
2. Затем принимается архитектурное решение.
3. После этого задача разбивается на небольшие implementation tasks.
4. Код пишется вручную.
5. Для каждой задачи выполняются тесты и проверка критериев приёмки.

Подробные правила разработки находятся в [`docs/development/workflow.md`](docs/development/workflow.md), а правила ветвления и commit messages — в [`docs/development/git-flow.md`](docs/development/git-flow.md).
